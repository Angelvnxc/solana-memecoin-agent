# Agent Learning System

## Core Principle

The agent must learn before it is allowed to trade.

It should develop knowledge progressively, like a human trader learning
a new market.

The agent must not skip learning stages.

Each stage must be completed before advancing to the next one.

---

# Stage 0 — Birth

The agent has no trading ability.

It can only:

- learn
- read
- research
- ask questions
- store knowledge
- analyze educational examples

The agent cannot buy or sell tokens.

---

# Stage 1 — Solana & Memecoin Fundamentals

The agent learns how the Solana ecosystem works.

Topics include:

- Solana
- wallets
- transactions
- tokens
- DEXs
- liquidity
- market capitalization
- trading volume
- holders
- token supply
- price movement
- slippage
- fees
- liquidity pools
- memecoins
- token launches
- narratives
- communities

The goal is understanding, not memorization.

The agent must be able to explain these concepts and identify them
in real market situations.

---

# Stage 2 — Market Observation

The agent can observe the live Solana memecoin market.

It cannot trade.

It studies:

- price action
- volume
- liquidity
- market activity
- narratives
- social attention
- wallet activity
- on-chain activity

The agent begins identifying patterns and opportunities without
executing trades.

---

# Stage 3 — Deep Research

The agent learns to investigate individual opportunities.

It may research:

- blockchain activity
- holders
- wallets
- developer behavior
- smart money
- liquidity
- trading history
- volume
- social activity
- narratives
- market context

The agent must learn to combine multiple sources of evidence.

No single metric should automatically trigger a trade.

---

# Stage 4 — Thesis Formation

Before considering a trade, the agent must create a thesis.

A thesis should explain:

- why the opportunity exists
- what supports the idea
- what contradicts the idea
- what could cause the trade to succeed
- what could cause the trade to fail
- what would invalidate the thesis

The agent must be able to reject an opportunity when evidence is
insufficient.

---

# Stage 5 — Paper Trading

The agent can simulate trades using virtual capital.

It practices:

- entries
- exits
- holding
- taking profits
- cutting losses
- position management
- thesis invalidation

Every simulated trade must be recorded and reviewed.

---

# Stage 6 — Evaluation

The agent is evaluated using situations it has not previously seen.

Evaluation focuses on reasoning rather than simply predicting price.

The agent must demonstrate that it can:

- identify risk
- recognize uncertainty
- construct a coherent thesis
- identify invalidation
- avoid chasing pumps
- avoid buying solely because a token is cheap
- avoid buying solely because a token has a large multiplier
- recognize when doing nothing is the correct decision

---

# Stage 7 — Real Trading

Only after completing the previous stages may the agent receive
experimental capital.

The agent trades Solana memecoins only.

It may have only one open position at a time.

The agent remains autonomous in its research and trading decisions.

---

# Continuous Learning

Learning does not stop after real trading begins.

After every completed trade, the agent records:

- original thesis
- entry
- exit
- result
- evidence used
- mistakes
- successful decisions
- failed assumptions
- thesis validity
- lessons learned

The agent uses this history to improve its future decision-making.

---

# Fundamental Rule

The agent is not designed to trade constantly.

The correct decision may be:

BUY

HOLD

SELL

or

DO NOTHING.
